# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2025-10-10

### Added
- Initial project structure with core infrastructure modules
- Amazon Connect instance creation and configuration
- Amazon Q in Connect integration
- Customer Profiles
- Amazon Connect Data Lake
- S3 buckets with intelligent lifecycle policies
- Lambda functions for custom integrations
- SAML 2.0 authentication support
- 70+ CloudWatch alarms with multi-tier alerting
- AWS Budget monitoring and cost protection
- SNS topics for alert routing
- Modular architecture separating core from custom extensions and parameter store
- Extensive documentation
